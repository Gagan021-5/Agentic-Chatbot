# SEO & Marketplace Patterns — RentPrompts

## App Naming Patterns
- Format: "BrandName: AI Subtitle" — e.g., "BrandForge: AI Logo Creator"
- Format: "ActionNoun + Domain" — e.g., "ScriptSpark AI"
- Format: "Catchy Compound" — e.g., "CropGuard Pro"
- Max 55 characters including subtitle
- Never use generic names: "Logo Maker", "Text Generator"
- Never include model names: lyria, gemini, groq, llama, GPT
- Power words: Forge, Studio, Craft, Spark, Genius, Pulse, Flow, Snap, Boost, Vault, Hive, Lens, Dash, Scope

## Description Rules
- Under 150 characters STRICT
- Lead with VALUE to user, not features
- Use action verbs: Transform, Generate, Create, Craft, Design, Analyze, Unlock
- Include "AI-powered" or "AI" naturally
- GOOD: "Transform any idea into a stunning brand logo in seconds with AI."
- BAD: "Creates logos in PNG format."

## Tag Strategy
- Exactly 7 tags
- Lowercase, hyphenated
- No # prefix
- Mix: 2 broad discovery + 3 niche use-case + 2 benefit/action
- GOOD: "brand-design", "ai-logo", "content-creator"
- BAD: "#brand-design", "png-output", "api-call"

## Category Options
creative, business, education, healthcare, entertainment, productivity, social, other

## High-Converting Patterns by App Type
### Image Apps
- Emphasize visual quality and speed
- Tags: "ai-design", "visual-creator", "instant-design"
- Description pattern: "Create stunning [output] from [input] in seconds with AI."

### Text Apps
- Emphasize quality and domain expertise
- Tags: "ai-writing", "content-creator", "smart-copy"
- Description pattern: "Craft polished, professional [output] — [benefit] with AI."

### Audio Apps
- Emphasize voice quality and naturalness
- Tags: "ai-voice", "text-to-speech", "audio-creator"
- Description pattern: "Transform text into natural, professional [output] instantly."

### Video Apps
- Emphasize cinematic quality and engagement
- Tags: "ai-video", "reel-maker", "content-studio"
- Description pattern: "Produce scroll-stopping [output] effortlessly with AI."
